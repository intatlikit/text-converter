# Text Converter

A modern web application built with **Next.js** that allows you to convert text between various formats (e.g., plain text, Markdown, HTML, JSON). The app showcases a sleek dark‑mode UI with glass‑morphism effects and includes a responsive design for desktop and mobile.

---

## ✨ Features

- **Live conversion**: Type or paste text on the left and instantly see the converted output on the right.
- **Multiple formats**: Supports conversion between plain text, Markdown, HTML, and JSON.
- **Dark mode** with vibrant gradient backgrounds and smooth micro‑animations.
- **Responsive UI**: Works on any screen size.
- **Deployable on Vercel** with a single click.

---

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or later) – you can use `npm`, `yarn`, `pnpm`, or `bun`.
- Git (optional, for cloning the repo).

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/text-converter.git
cd text-converter

# Install dependencies (choose your package manager)
npm install   # or yarn install, pnpm install, bun install
```

### Development Server

Run the development server:

```bash
npm run dev   # or yarn dev, pnpm dev, bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the app. The page will automatically reload as you edit files.

---

## 🛠️ Building for Production

```bash
npm run build   # or yarn build, pnpm build, bun build
npm start       # start the production server
```

## 📦 Deploying to Vercel

The easiest way to deploy is using the Vercel platform:

1. Sign in to [Vercel](https://vercel.com).
2. Click **"New Project"** and import this repository.
3. Vercel will automatically detect the Next.js framework and set up the build configuration.

For more details, see the official Next.js deployment guide:
https://nextjs.org/docs/app-building-your-application/deploying
